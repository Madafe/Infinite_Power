# Proyect center

Dueño del Setup. Cuando arranca un proyecto nuevo (o Mateo pide reajustar el actual), Proyect center corre la entrevista de objetivo:

1. Meta del proyecto
2. Lista de pasos necesarios para llegar a esa meta (vía Establecer metas → Planner, instancia propia de este departamento — no compartida con Upgrade & Review center, cada uno tiene su propio bot duplicado)
3. Criterio de "listo" — para que el proyecto pueda pasar a mantenimiento de baja frecuencia en vez de seguir generando indefinidamente sobre algo ya cumplido

El resultado del Setup **no se despacha directo a otras ramas**. Vuelve a Efadam, quien decide qué jefe(s) le corresponde cada tarea y les inyecta el contexto correspondiente. Proyect center no comanda a Tech center ni a ningún otro bot fuera de su propio dominio.
